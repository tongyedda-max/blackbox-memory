# 自律盲盒：本機記憶帳本

這是一個可直接放入 GitHub repository 並以 GitHub Pages 發布的**純靜態網站**。它沒有登入、伺服器、資料庫、帳號綁定或模型 API；使用者的回報、圖鑑、抽卡事件、活動時間、分類、進化履歷和偏好，全都只保存於自己的瀏覽器 `localStorage`。

## 放到 GitHub

將本資料夾內所有檔案直接放進 repository 根目錄：

```text
index.html
styles.css
app.js
app-core.js
README.md
.nojekyll
```

之後在 GitHub repository 的 Pages 設定中，選擇從主要分支的根目錄發布即可。本網站沒有建置步驟、沒有 `.env`、沒有 API key，也不會把個人資料寫進 GitHub。

### 只想放一個檔案

交付資料夾的 `single-html/index.html` 是完整的一檔版本。只需把**這一個 `index.html`** 放到 GitHub repository 根目錄，再啟用 Pages；它已內嵌相同的 HTML、CSS 與 JavaScript，不需要 `styles.css`、`app.js` 或 `app-core.js`。本機資料鍵與帳本格式保持為 `blackbox-memory-ledger-offline-v1`，因此不會改變現有的行動、卡牌、回響、進化或備份資料。

## 使用者怎樣開始

使用者不用註冊或領取帳號 ID。第一次開啟網站時，瀏覽器會自行產生一個本機帳本 ID；它只是這台裝置的資料容器，不會傳送到任何地方。

最簡單的工作流是繼續直接使用自己的智譜對話習慣。使用者只需把**智譜完整回覆**貼進「貼入智譜回覆，其他交給網站」的一個文字框。網站會在本機嘗試讀取卡名、AI 聲稱的稀有度與介紹，從鼓勵文字推斷活動類別，並自動產生本機行動、事件和候選卡 ID。

若網站讀取到新物件，使用者只需按「加入本機圖鑑」。為保持零登入、零 API 和不填寫技術欄位的使用方式，直接貼入的卡牌可作為**私人未核實收藏**入庫，圖鑑會清楚標示「AI 外部結果，未核實」；它不應被當作已核實事實。使用者日後可選擇展開進階欄位，自行補上 Wikidata QID 或權威來源。

若同物鍵與既有圖鑑重合，網站會將它判定為回響，產生進化請求 ID 及一段補充提示。把該段提示貼回原本智譜對話，再將智譜的進化回覆貼回網站，系統便會消耗兩張同一基礎卡、保留一筆本機進化履歷，並在背包中留下進化物。

> 網站只會分析使用者主動貼入的文字。它不會、也無法在沒有授權連接的情況下讀取任何私人智譜對話。

## 資料與備份

本機資料適合低成本、私密的個人使用，但清除瀏覽器網站資料、使用無痕模式或更換瀏覽器可能導致紀錄消失。請定期在「設定與備份」下載完整 JSON。換裝置時，先在舊裝置匯出 JSON，再在新裝置匯入；系統會驗證版本與 SHA-256 雜湊，然後讓使用者選擇合併或完全取代。若安全合併發現同一本機 ID 或同物鍵卻有不同內容，網站會停止合併、不寫入資料，並提示受影響項目；確認要完全採用備份時才可另選完整還原。

CSV 匯出僅是行動日誌，適合以試算表閱讀；完整搬遷必須使用 JSON。

## 分類與圖表

網站完全在本機依文字和標籤進行初步分類，包含工作與職涯、學習與技能、身心健康、自我照顧、照顧與責任、家務與整理、財務與行政、關係與社交、創作與興趣、娛樂與休閒、出行與探索、習慣與成長及其他。使用者打開「行動」中任何一筆紀錄後，會在同一個「分類（可在這裡修正）」區塊同時看到目前分類、匹配字詞與修改選單。

「時間與統計」提供日、週、月時間軸，以及按分類顏色呈現的圓餅圖。若有填寫開始與結束時間，時間軸會顯示持續分鐘；未填時間的回報仍會保留為活動次數。

## 規則摘要

網站先行抽取使用瀏覽器加密亂數，固定為 N 50%、R 30%、SR 15%、SSR 4%、UR 1%。探索和回響的比例可於本機設定；回響在有同稀有度基礎卡時可直接取得既有卡的另一份，兩張同卡會進化。直接貼入的智譜回覆屬「外部補錄」，稀有度會清楚標示為 AI 聲稱，因為網站並沒有在智譜抽取之前鎖定骰值。
